# 城市出片点地图（第一版 Demo）

一个纯前端的「拍照出片点 + 地铁通达性分析」网页，用来做求职作品集。

## 怎么打开

点击右侧 Artifact 面板的 **Preview** 标签即可在浏览器里运行（它会自动起一个本地服务器）。
> 注意：不要直接双击 `index.html` 用 file:// 打开，因为那样浏览器会拦截读取 JSON 数据（CORS 限制）。

## 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 页面本体：地图 + 缓冲区分析 + 通达性统计逻辑 |
| `spots.json` | 出片点数据（你的"小数据库"），改这个就能加/减点位 |
| `metro.json` | 地铁口数据 |

## 怎么加一个出片点

打开 `spots.json`，照着已有格式加一条：

```json
{
  "name": "点位的名字",
  "lng": 114.0000,
  "lat": 22.5000,
  "tags": ["夜景", "海边"],
  "note": "一句点评",
  "best_time": "夜晚"
}
```

坐标（lng/lat）可以从地图拾取器拿到（如高德/百度「坐标拾取器」，或 OSM 右键）。
